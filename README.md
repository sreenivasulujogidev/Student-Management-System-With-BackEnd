# Student Management System

A backend-based Student Management System built using **Node.js, Express.js, MongoDB, and Mongoose**.

## Features

- Add Student
- Get Student
- Get All Students
- Update Student
- Delete Student

## Technologies Used

- HTML
- CSS
- JavaScript
- Axios
- Node.js
- Express.js
- MongoDB
- Mongoose

## 🔗 REST API

The application uses RESTful API endpoints for student management.

| Method   | Endpoint           | Description                             |
| -------- | ------------------ | --------------------------------------- |
| `POST`   | `/students`        | Add a new student                       |
| `GET`    | `/students/:regNo` | Get a student by Registration Number    |
| `GET`    | `/students`        | Get all students                        |
| `PATCH`  | `/students/:regNo` | Update selected student fields          |
| `DELETE` | `/students/:regNo` | Delete a student by Registration Number |
